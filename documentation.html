Dokumentasi & Pertanyaan Umum (FAQ)

1. Apakah aman menggunakan ALIP ENCRYPTOR?

Sangat aman. Seluruh proses enkripsi dan dekripsi berjalan secara lokal di browser Anda (Client-Side) menggunakan Web Crypto API standar industri. File Anda tidak pernah diunggah ke server mana pun.

2. Apa itu format .alipenc?

Format kontainer kustom yang menyimpan metadata nama file asli, salt, IV acak kriptografis, serta cipher teks dari AES-256-GCM.

3. Apakah Obfuscation sama dengan Enkripsi?

Tidak. Obfuscation hanya mempersulit pembacaan kode sumber oleh manusia, sedangkan enkripsi mengunci data secara total menggunakan kunci rahasia.
